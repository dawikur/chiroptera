# Security policy

## Supported versions

Security fixes are made for the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately to [Dawid Kurek](mailto:hello@dawikur.dev) with:

- a description of the issue and its potential impact;
- steps to reproduce it or a proof of concept;
- affected versions and any suggested mitigation, if known.

You should receive an acknowledgement within seven days. After triage, we will
coordinate disclosure and a fix according to the issue's severity.

## Scope

This policy covers the Python package, CLI, generator scripts, and repository
CI configuration. Visual defects, contrast concerns, missing highlight groups,
and plugin compatibility issues are not security vulnerabilities; please
report them through regular GitHub issues.
